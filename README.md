[The Self-Checkout Is Judging You](https://make.fun/c/u-motasimfuad-the-self-checkout-is-judging-you-b71130d6):
one funny line in the voice of a smug, judgmental self-checkout machine.

## The line

> Twelve yoghurts, no spoon, no plan — and you scanned your loyalty card like it earns you a personality.

## How it works

`main.py` is a small deterministic program: no randomness, no network, no
clock. It writes exactly that one line (103 characters) to
`/output/entry.txt`, byte-identical on every run.

Run it with:

```sh
python3 main.py
```
